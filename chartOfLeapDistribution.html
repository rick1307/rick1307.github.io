Ledger History
Notional design

One chart form, multiple views. The page uses one shared dataset and lets JavaScript decide whether to show organized crew, total LEAP holders, both together, or the derived Reach relationship. The current history is illustrative only; no historical snapshot writes are enabled here.

What the same snapshot can support

The chart changes presentation, not underlying observations. Crew and holders are the stored facts; Reach is derived.

CrewHistorical organized-community count from C.
HoldersHistorical wallets possessing LEAP from H.
CompareSuperimposes C and H from the same snapshots.
ReachCalculated at each point as H ÷ C; it does not need its own stored value.
One datasetEvery view can be rebuilt from the same sequence of snapshot records.
Future viewsAdditional presentations can be added in JavaScript without creating another HTML page.
