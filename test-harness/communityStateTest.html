Community State Test

Question this harness answers: can the current Community Operating Wallet publish one canonical Wild Ledger STATE value to XRPL and can Wild Ledger reconstruct that exact value from validated history?

This harness writes to XRPL. It uses the reserved diagnostic key HARNESS, not CONFIG, so this test does not replace a community's real configuration pointer. The final submit creates permanent ledger history and charges the normal XRPL transaction fee.
