About this test

Use this harness only for a brand-new community. A later Operating Wallet replacement must follow the established-community authority transition path.

This helper validates the entered authority syntax, requires the connected Bifrost signer to match the entered Owner Wallet, prepares and signs a no-op AccountSet, and writes the first Operating Wallet authority statement to XRPL only in Step 5.

This helper does not independently resolve the canonical Owner Wallet from XRPL history; it uses the Owner Wallet address you enter and enforces an exact signer match.

Human path on the surface. Technical proof underneath. Green checks all the way down means the harness completed successfully.
