About this test

Owner Wallet mode publishes the first canonical Wild Ledger Owner Wallet self-statement and refuses to publish a second one if the canonical statement already exists.

Operating Wallet mode publishes the first Operating Wallet statement for a brand-new community. Do not use it to rotate an established community's Operating Wallet; use the authority-transition harness instead.
