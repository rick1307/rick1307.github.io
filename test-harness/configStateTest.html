CONFIG State Harness

Question this harness answers: can the current Community Operating Wallet publish the community's CONFIG schema state to XRPL, can Wild Ledger independently reconstruct it, then reload and validate the complete current off-ledger CONFIG before entering the Operator backend?

This harness writes to XRPL. It publishes WILD-LEDGER/STATE/<COMMUNITY-ID>/CONFIG=1. Here 1 means CONFIG Schema 1, not a configuration-history version.
