Wallet Proof Test

Use this when you need to answer one question: does the person holding this connected wallet actually control the XRPL account it claims?

No XRPL transaction is submitted. This harness asks the wallet to sign a short-lived challenge, verifies that proof locally, and then confirms the same proof cannot be reused.

When do I use this harness?
Use it when wallet ownership itself is the thing you need to isolate. It does not identify a community, create an Operator session, change authority, or write to XRPL. A clean pass tells you the connected XRPL account can produce a valid one-time cryptographic proof and that Wild Ledger rejects reuse of that proof.
