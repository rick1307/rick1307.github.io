When do I use this harness?
Use it when wallet ownership itself is the thing you need to isolate. It does not identify a community, create an Operator session, change authority, or write to XRPL. A clean pass means the connected account produced a valid one-time cryptographic proof and Wild Ledger rejected reuse of that proof.
