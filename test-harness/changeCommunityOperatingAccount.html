About this test
Use this harness to establish or change a community's canonical Operating Wallet authority statement. For an existing community, the currently canonical Operating Wallet must sign the replacement. If the first on-ledger statement has not yet been published, the configured current Operating Wallet must publish the initial statement naming itself. Emergency recovery is not defined by this harness.
