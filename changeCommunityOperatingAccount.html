Operating Wallet

This wallet is the community's on-ledger operating identity. It creates recognition Checks and publishes community protocol statements. Wild Ledger resolves the current wallet from the latest valid XRPL authority statement.

Operating Wallet authority

The canonical state key is OPERATING-WALLET. If an existing community has not published its first on-ledger value yet, its configured current Operating Wallet publishes that first statement naming itself. After that, the currently resolved Operating Wallet may name a replacement directly.
