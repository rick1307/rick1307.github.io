Establish a New Community Operating Wallet

This page is for a brand-new community. The current Wild Ledger Owner Wallet signs the first canonical OPERATING-WALLET statement, and the memo names the new community's Operating Wallet.

Important

Do not use this page to rotate an established community's Operating Wallet. A later replacement must be signed by that community's current canonical Operating Wallet.

Exact authority syntax

Type the full canonical memo yourself. Replace with that community's exact Community ID, and replace with that community's exact XRPL Operating Wallet address. This page will verify the syntax and make sure the address after the equals sign exactly matches the new Operating Wallet above.
